# Alchemist

> **Ask your local data what it knows.** A local-first macOS desktop app that opens your databases, MemPalace, and config files — and lets you ask questions in plain English.

![Alchemist app icon](src-tauri/icons/icon.png)

---

## Features

- **Open any SQLite file** — drag-drop or file picker, read-only, safe
- **Connect to MemPalace** — browse wings/rooms/drawers, search by meaning
- **Natural language queries** — type plain English, get SQL generated by your local LLM
- **SQL preview** — see and edit the generated SQL before it runs
- **Charts & tables** — results as bar, line, or pie charts
- **Saved spells** — reuse successful queries across sessions
- **Multiple providers** — Ollama (local), OpenAI, Gemini, DeepSeek
- **100% local** — no cloud, no accounts, no data leaves your machine

## Installation

1. Download the latest DMG from [Releases](https://github.com/witchdaddylabs/alchemist/releases)
2. Mount the DMG and drag Alchemist to your Applications folder
3. Open Alchemist from Applications (Gatekeeper may ask you to confirm)

### Requirements

- macOS 13 (Ventura) or later
- Apple Silicon or Intel
- [Ollama](https://ollama.com) (recommended for local AI) or a cloud provider API key

## Quick Start

1. **Open Alchemist** — it auto-detects MemPalace if you have one
2. **Or open a SQLite file** — drag a `.db` or `.sqlite` file onto the vault screen
3. **Explore the schema** — see tables, columns, and relationships in the sidebar
4. **Ask a question** — type something like "how many users signed up last month?" in the chat
5. **Review the SQL** — edit if needed, then hit Run
6. **See results** — table, summary, or chart view

### Provider Setup

**Ollama (local — recommended):**
1. Install Ollama from [ollama.com](https://ollama.com)
2. Pull a model: `ollama pull llama3.2`
3. In Alchemist Settings, Ollama is auto-detected

**Cloud providers:**
- **OpenAI** — add your API key in Settings → OpenAI
- **Gemini** — add your Google AI Studio key in Settings → Google AI
- **DeepSeek** — add your DeepSeek API key in Settings → DeepSeek

Keys are stored in macOS Keychain — never in plaintext.

## Development

```bash
# Clone and install
git clone https://github.com/witchdaddylabs/alchemist.git
cd alchemist
npm install

# Run in development mode
npm run tauri dev

# Build for distribution
npm run tauri build
```

## Security

- **Read-only by design** — SQLite opened with `SQLITE_OPEN_READONLY`
- **SQL validation** — `sqlparser-rs` blocks writes, multi-statements, dangerous pragmas
- **Keychain storage** — API keys in macOS Keychain, never in files
- **No telemetry** — no analytics, no crash reporting, no network calls to WDL servers
- **Auto-updates** — signed releases via GitHub, checked on launch
